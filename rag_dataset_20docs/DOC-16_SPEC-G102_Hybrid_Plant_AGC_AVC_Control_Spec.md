## 1. 系统控制指标与 SLA 性能要求

风光储联合控制系统通过集中式能量管理系统（EMS）接收省/地调度下发的自动发电控制（AGC）与自动电压控制（AVC）指令，控制系统须满足以下硬性 SLA 指标：

### 1.1 动态响应与调节精度表

| 指标名称 | 调度规范要求 | 储能（BESS）响应 | 风电/光伏响应 | 联合系统综合性能 |
| :--- | :--- | :--- | :--- | :--- |
| **AGC 有功响应时间** | $< 200	ext{ ms}$ | $\le 50	ext{ ms}$ | $1.5	ext{–}3.0	ext{ s}$ | **$< 180	ext{ ms}$** |
| **AVC 无功响应时间** | $< 100	ext{ ms}$ | $\le 30	ext{ ms}$ | $200	ext{–}500	ext{ ms}$ | **$< 80	ext{ ms}$** |
| **有功爬坡速率** | $\ge 10	ext{ MW/min}$ | $\ge 50	ext{ MW/s}$ | $5	ext{–}10	ext{ MW/min}$ | **$10	ext{–}30	ext{ MW/min}$** |
| **有功调节精度** | $\le \pm 1.0\%$ | $\le \pm 0.2\%$ | $\le \pm 1.5\%$ | **$\le \pm 0.5\%$** |
| **无功调节精度** | $\le \pm 1.5\%$ | $\le \pm 0.3\%$ | $\le \pm 2.0\%$ | **$\le \pm 0.8\%$** |
| **频率死区** | $\pm 0.03	ext{ Hz}$ | $\pm 0.01	ext{ Hz}$ | $\pm 0.05	ext{ Hz}$ | **$\pm 0.03	ext{ Hz}$** |
| **电压死区** | $\pm 0.5	ext{ kV}$ | $\pm 0.1	ext{ kV}$ | $\pm 0.5	ext{ kV}$ | **$\pm 0.5	ext{ kV}$** |

## 2. 联合 AGC 有功功率分配算法逻辑

为兼顾响应速度、设备寿命与储能荷电状态（SoC），EMS 采用三层嵌套的功率分配逻辑：

```
[调度 AGC 指令 P_grid] 
        │
        ▼
┌────────────────────────────────────────────────────────┐
│ 频差/功率偏差计算: ΔP = P_grid - P_actual + K_f * Δf   │
└──────────────────────────┬─────────────────────────────┘
                           │
        ┌──────────────────┴──────────────────┐
        ▼                                     ▼
┌─────────────────────────────┐   ┌─────────────────────────────┐
│ 快速高频分量 (高频/瞬态)    │   │ 稳态长周期分量 (低频/趋势)   │
│ 优先分配给 BESS 储能系统    │   │ 依据最大功率点分配给风电/光伏│
└──────────────┬──────────────┘   └──────────────┬──────────────┘
               │                                 │
               ▼                                 ▼
┌─────────────────────────────┐   ┌─────────────────────────────┐
│ BESS SoC 约束判定 (20%-80%) │   │ 风/光弃风弃光与限制曲线判定 │
└─────────────────────────────┘   └─────────────────────────────┘
```

### 2.1 储能 SoC 动态调节因子
当储能电池处于不同 SoC 区间时，EMS 自动调整其 AGC 分配权重系数 $lpha_{	ext{bess}}$：
- **$40\% \le 	ext{SoC} \le 70\%$（健康区间）**：$lpha_{	ext{bess}} = 1.0$，全功能参与高频调频与功率填谷。
- **$20\% \le 	ext{SoC} < 40\%$（偏低区间）**：限制放电功率，$lpha_{	ext{dis}} = (	ext{SoC} - 20)/20$，优先执行充电指令。
- **$	ext{SoC} < 20\%$（告警下限）**：强制退出 AGC 调频放电，仅允许充电保护。
- **$	ext{SoC} > 80\%$（偏高区间）**：限制充电功率，$lpha_{	ext{chg}} = (100 - 	ext{SoC})/20$，优先执行放电指令。

## 3. 通信 SLA 与降级运行防线

1. **通信协议与时延**：EMS 与局调度端采用 IEC 60870-5-104 协议，站内与风机/逆变器/PCS 采用 1000Mbps 光纤冗余 Modbus TCP 环网，保证站内数据采集时延 $< 20	ext{ ms}$。
2. **通信中断降级模式 (Heartbeat Failure)**：
   - 当 EMS 与调度端通信中断超过 **5.0 秒**，系统自动保持当前功率出线 **30 秒**，随后启动自动降额，按 **10 MW/min** 的速率平滑降至安全备用功率（如 50% 额定功率）。
   - 当 EMS 与储能 BMS 通信中断超过 **1.0 秒**，储能 PCS 立即退出 AGC/AVC 联合控制，切回本地定功率保护模式。
